About

AppSync Unified patches installd on jailbroken devices so ad-hoc, self-signed, or expired IPA packages (such as LegacyTG dev builds) can be installed via ideviceinstaller or on-device installers.

Original package by Karen (angelXwind). Hosted here as an unmodified mirror with full attribution for convenience when setting up test devices.
